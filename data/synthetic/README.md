# Synthetic ERP-Style Data

This directory contains synthetic or appropriately de-identified ERP-style datasets used for development, testing, and evaluation of the AI-Enabled ERP Decision Support proof of concept.

The datasets are designed to represent common ERP-related information such as:

- Financial transactions
- Project costs and budgets
- Project progress
- Transaction dates
- Departments or business units
- Exception-related transaction patterns

No confidential production ERP data is included in this directory.

Synthetic datasets will be added and updated as the prototype development progresses.
